Active Branch Policy

- Primary working branch for this fork: `dev/mc-aixi-local` (long‑lived).
- `main` tracks upstream; do not target feature work to `main` here.
- Open pull requests against `dev/mc-aixi-local` unless explicitly contributing upstream.
- If you fork this repo, consider keeping your own long‑lived branch to isolate local direction.

Notes
- CI and release flows should reference `dev/mc-aixi-local` as the default base for changes within this fork.
- The `doc/html/`, `graph/`, and `log/` directories are intentionally tracked in this fork.
